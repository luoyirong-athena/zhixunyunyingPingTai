# 志询CRM - 抖音客户采集 Chrome 插件

在抖音用户主页一键提取客户信息到志询CRM。

## 安装方法

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开 **"开发者模式"**
3. 点击左上角 **"加载已解压的扩展程序"**
4. 选择本文件夹（`client/extension/`）
5. 安装完成，Chrome 工具栏会出现插件图标

## 使用方法

1. 确保 CRM 已启动（`node server/src/index.js`）
2. 点击插件图标 → 确认 CRM 地址为 `http://localhost:3317`
3. 打开任意抖音用户主页（如 `https://www.douyin.com/user/xxxxx`）
4. 页面右下角会出现 **📋 采集到CRM** 按钮
5. 点击按钮 → 自动提取昵称、抖音号、粉丝数、手机号 → 发送到 CRM
6. 在 CRM 客户采集页 → 轮询拉取 → 数据出现在采集表格中

## 注意事项

- 请确保在**抖音用户主页**使用（URL 包含 `/user/`）
- 不要在搜索结果页使用（那里内容太多，插件不提取）
- CRM 必须启动且端口正确
